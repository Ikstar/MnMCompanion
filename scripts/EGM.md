# scripts

## Overview
Build, release, synthetic fixture generation, and screenshot automation scripts for `MnMCompanion`. This package handles end-to-end Windows single-file release packaging with SHA-256 verification and GitHub Release publishing, changelog note extraction, deterministic synthetic game ledger and auction feed generation, and off-screen UI screenshot rendering for repository documentation.

## Interface
- [`build-release.ps1`](./build-release.ps1) — `scripts\build-release.ps1 [-Publish] [-Notes <string>]`
  - **Arguments**: `-Publish` (`[switch]`, optional) creates GitHub Release `v<Version>` and uploads artifacts via `gh`; `-Notes` (`[string]`, optional, default `""`) overrides `CHANGELOG.md` notes body when `-Publish` is set.
  - **Inputs**: `$PSScriptRoot`-anchored repository paths (`MnMCompanion.sln`, `<Version>` from `src/MnMCompanion/MnMCompanion.csproj`, `dist/`) and `CHANGELOG.md` (via [`release-notes.ps1`](./release-notes.ps1) when `-Publish` is set and `-Notes` is omitted).
  - **Outputs**: Self-contained `win-x64` single-file `dist/MnMCompanion.exe`, ASCII checksum file `dist/MnMCompanion.exe.sha256`, and (with `-Publish`) GitHub Release `v<Version>` titled `"Companion <Version>"` whose release notes always end with an appended download and `(Get-FileHash MnMCompanion.exe).Hash` SHA-256 verification footer (whether the body came from `CHANGELOG.md` or `-Notes`).
- [`release-notes.ps1`](./release-notes.ps1) — `scripts\release-notes.ps1 -Version <X.Y.Z> [-Path <string>]`
  - **Arguments**: `-Version` (`[string]`, mandatory) semantic version to extract; `-Path` (`[string]`, optional, default `Join-Path (Split-Path $PSScriptRoot -Parent) 'CHANGELOG.md'`, resolved relative to `$PSScriptRoot`) path to the changelog file.
  - **Inputs**: UTF-8 `CHANGELOG.md` section headed `## <Version> (yyyy-mm-dd)`.
  - **Outputs**: Pipeline string formatted as `**Companion <Version>**` followed by the trimmed changelog entry with `^\s{2,}\S` continuation lines joined onto any preceding non-blank line and `](README.md#` and `](docs/FAQ.md#` links rewritten to `https://github.com/ExploreTheFloor/MnMCompanion#` and `https://github.com/ExploreTheFloor/MnMCompanion/blob/main/docs/FAQ.md#`.
- [`make-demo-ledger.py`](./make-demo-ledger.py) — `python scripts/make-demo-ledger.py [OUT] [DAY]`
  - **Arguments**: `argv[1]` `OUT` (`str`, optional, default `"demo-game-data"` relative to caller CWD) root output folder; `argv[2]` `DAY` (`str`, optional, format `yyyy-MM-dd`, default local midnight today) session date.
  - **Helpers**: `b64(text)`, `stamp(t)`, `row(act, f02, detail, t, zone, level, actor, cls, kind)`, `add(act, f02, detail, t, zone, who, kind_for_owner_twin=True)`, `coin(copper)`, `coin_words(copper)`, `mine(act, f02, detail, at, zone)`, `trade(at, partner, gave_coin, gave_items, got_coin, got_items)` (with nested `side(act, coin, items, summary)`).
  - **Inputs**: Built-in synthetic constants (`OWNER`, `SERVER`, `TZ`, `PARTY`, `CAMPS`, `PRICES`, `SOLD`) modeling party combat loot, gathering, vendor sales/purchases, bag drops/destroys, and player trades.
  - **Outputs**: `<OUT>/demoserver/Brindlewick/Ledger/Brindlewick_Character_<YYYY-MM-DD>.json` and `<OUT>/demoserver/Brindlewick/Ledger/Brindlewick_Social_<YYYY-MM-DD>.json`, plus a stdout row-count summary.
- [`make-demo-market.py`](./make-demo-market.py) — `python scripts/make-demo-market.py [OUT] [NOW]`
  - **Arguments**: `argv[1]` `OUT` (`str`, optional, default `"demo-auctions.json"` relative to caller CWD) output JSON path; `argv[2]` `NOW` (`str`, optional, format `yyyy-MM-ddTHH:mm:ssZ`, default current UTC second) feed generation timestamp.
  - **Helpers**: `coin(c)`, `stamp(t)`.
  - **Inputs**: Built-in synthetic constants (`SERVER = "Demoserver"`, `PLAYERS`, `STACK = 20`, `BULK`, `MARKET`, `CARDS`) overlapping items from [`make-demo-ledger.py`](./make-demo-ledger.py).
  - **Outputs**: UTF-8 JSON file at `<OUT>` matching the `mnm-db.com` auction feed schema (`generatedAt`, `capture`, `listings`, `requests`, `stats`, `stacks`), plus a stdout count summary.
- [`make-screenshots.ps1`](./make-screenshots.ps1) — `scripts\make-screenshots.ps1 [-Exe <string>] [-Out <string>] [-Recipes <string>]`
  - **Arguments**: `-Exe` (`[string]`, optional, default `Join-Path $PSScriptRoot '..\src\MnMCompanion\bin\Debug\net9.0-windows\MnMCompanion.exe'`); `-Out` (`[string]`, optional, default `Join-Path $PSScriptRoot '..\docs\images'`); `-Recipes` (`[string]`, optional, default `""`) path to a wiki tradeskills/recipes JSON file (`recipes.json` or `monstersandmemories.wiki/api/tradeskills`). Both `-Exe` and `-Out` defaults resolve relative to `$PSScriptRoot` rather than the caller's working directory.
  - **Helpers**: `Shot([string]$name, [string[]]$more)` (invokes `--snapshot` and verifies PNG output), `Blank($c)` (tests pixel alpha `< 10` for border cropping).
  - **Inputs**: Built `MnMCompanion.exe`, Python 3 runtime executing [`make-demo-ledger.py`](./make-demo-ledger.py) and [`make-demo-market.py`](./make-demo-market.py), and optional `-Recipes` JSON file.
  - **Outputs**: 26 trimmed PNG screenshots in `<Out>` (29 PNGs when `-Recipes` is supplied, adding `window-recipes-skills.png`, `window-recipes.png`, and `window-recipes-search.png`) and a stdout table of PNG sizes.

## Invariants
- **Semantic Version & Pre-Publish Test Gate ([`build-release.ps1`](./build-release.ps1), [`release-notes.ps1`](./release-notes.ps1))**: Version strings must strictly match `^\d+\.\d+\.\d+$`. `build-release.ps1` runs `dotnet test MnMCompanion.sln` first and aborts before deleting `dist/` or building if any test fails.
- **SHA-256 Format, Self-Check Smoke Gate & Release Footer ([`build-release.ps1`](./build-release.ps1))**: `dist/MnMCompanion.exe.sha256` is always ASCII-encoded as `<64 lowercase hex>  MnMCompanion.exe` (two spaces), matching the self-updater's verification format. The built binary must execute `--about --report <dist/about-check.txt>` and report `Companion <Version>` before the build succeeds or publishes, and `-Publish` unconditionally appends the download and `(Get-FileHash MnMCompanion.exe).Hash` SHA-256 verification footer to `$notes` even when `-Notes` overrides `CHANGELOG.md`.
- **Non-Empty Changelog, Continuation Joining & Link Rewriting ([`release-notes.ps1`](./release-notes.ps1))**: `CHANGELOG.md` must exist and contain a non-empty section headed `## <Version> (yyyy-mm-dd)`. Indented continuation lines (`^\s{2,}\S`) are joined onto any preceding non-blank line, and specifically `](README.md#` and `](docs/FAQ.md#` links are rewritten to `https://github.com/ExploreTheFloor/MnMCompanion` anchors/blob URLs.
- **Deterministic RNG & Synthetic Identity Privacy ([`make-demo-ledger.py`](./make-demo-ledger.py), [`make-demo-market.py`](./make-demo-market.py), [`make-screenshots.ps1`](./make-screenshots.ps1))**: Both Python scripts seed deterministic generators (`random.Random(2026)`) and emit exclusively synthetic names so demos and screenshots never expose real players. `make-demo-ledger.py` uses owner `Brindlewick` on `demoserver`, party members `Tamsin`, `Orrin`, `Pip`, `Vesna`, `Garrick`, and trader refs `ref_71358`, `ref_20917`, `ref_38206`, `ref_65143`; `make-demo-market.py` uses `SERVER = "Demoserver"` and 24 synthetic players (`Avelin`–`Yorath`) with unique `(player, item)` pairs across standard `MARKET` entries.
- **Ledger Envelope & Unpriced Item Coverage ([`make-demo-ledger.py`](./make-demo-ledger.py))**: Output ledgers wrap `f04`-sorted event rows in `{c01, c02, c03, c04: 0, c05: "Brindlewick", c06: 1}` with 7-digit fractional `-05:00` timestamps (`TZ`), Base64-encoded `zone_` / `name_` tokens, `f08 = 0` (`Character`) vs. `f08 = 2` (`Social`), and paired `act_16`/`act_20` rows at identical timestamps for trades. Specific looted items (`Hide Scraps`, `Crocodile Hide`, `Antique Ceramic Fragment`, `Raw Human Meat`, `Fish Bones`, `Pristine Crocodile Hide`) are intentionally never sold to vendors so estimated and unpriced UI paths remain exercised.
- **Market Bulk Coverage & Edge-Case Rows ([`make-demo-market.py`](./make-demo-market.py))**: All 13 `BULK` materials appear as lowercase keys mapped to `STACK = 20` in `stacks`, whereas `"Bronze Scraps"` and `"Pungent Healing Herbs"` are omitted from `MARKET` and `CARDS`—leaving 11 bulk materials that emit stack-priced `listings` (`unit = price // 20`, `stack = 20`, `perStack = True`) and lowercase `stats` cards alongside the 15 non-bulk `MARKET`/`CARDS` items. Three edge-case listings (`Flux` with `price: None`, `TB` with `matched: False`, `Wolf Pelt` with `intent: None`) are always appended, and `listings` is sorted descending by `seen`.
- **Off-Screen Snapshot Isolation & Margin Trimming ([`make-screenshots.ps1`](./make-screenshots.ps1))**: Screenshots are rendered off-screen via `--ledger <temp> --character Brindlewick --snapshot <png>` without querying live external services or writing `settings.json` (`--ledger` sets `Settings.ReadOnly = true`, though child runs still load existing `AppFolder.Folder\settings.json` in read-only mode because `MNMCOMPANION_DATA` is not overridden). Omitting `-Recipes` skips only the 3 recipe screenshots without error; every `*.png` in `<Out>` has transparent right and bottom margins (`Alpha < 10`, sampled every 3 pixels while keeping width/height `>= 1`) trimmed in place.

## Side Effects
- **[`build-release.ps1`](./build-release.ps1)**: Executes `dotnet test` against `MnMCompanion.sln`; deletes and recreates `dist/`; runs `dotnet publish` to write `dist/MnMCompanion.exe`; writes `dist/MnMCompanion.exe.sha256`; spawns `dist/MnMCompanion.exe --about --report dist/about-check.txt` and deletes `about-check.txt`; when `-Publish` is set, appends the download/`Get-FileHash` verification footer to `$notes` and invokes `gh release create v<Version>` over the network to create a GitHub Release/tag and upload `MnMCompanion.exe` and `MnMCompanion.exe.sha256`.
- **[`release-notes.ps1`](./release-notes.ps1)**: Read-only filesystem read of `CHANGELOG.md`; writes formatted release notes to stdout/pipeline with zero file mutations or network calls.
- **[`make-demo-ledger.py`](./make-demo-ledger.py)**: Creates `<OUT>/demoserver/Brindlewick/Ledger/` and writes/overwrites UTF-8 JSON files `Brindlewick_Character_<YYYY-MM-DD>.json` and `Brindlewick_Social_<YYYY-MM-DD>.json`. Zero network calls.
- **[`make-demo-market.py`](./make-demo-market.py)**: Writes/overwrites UTF-8 JSON file `<OUT>` (default `demo-auctions.json`). Zero network calls.
- **[`make-screenshots.ps1`](./make-screenshots.ps1)**: Creates `<Out>` (default `../docs/images` relative to `$PSScriptRoot`) and temporary folder `%TEMP%/mnmcompanion-demo-<guid>` (deleted in `finally`); spawns `python` to generate demo ledger and market JSON fixtures; spawns `MnMCompanion.exe --snapshot` 26 times (29 with `-Recipes`) without setting `MNMCOMPANION_DATA`—so each child run reads `%LOCALAPPDATA%\MnMCompanion\settings.json` (`AppFolder.Folder`) in `ReadOnly` mode, points `LootStore` state at `LedgerDb.OtherFolder($demo)`, and creates/deletes per-shot `%TEMP%\mnmcompanion-snapshot-<guid>.db` (plus `-wal`/`-shm`) or `%TEMP%\mnmcompanion-timers-<guid>` scratch artifacts; deletes prior target PNGs and `<png>.txt` sidecars; and rewrites cropped `*.png` files in `<Out>` via temporary `.png.tmp` files.
