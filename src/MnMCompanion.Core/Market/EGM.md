# Market

## Overview
Maintains the persistent local auction price book (`market.json`), parses `mnm-db.com` auction snapshots (`auctions.json`), classifies wiki item cards, computes standing ask/bid medians and historical price trends, and enforces HTTP polling rate limits (`namespace MnMCompanion.Market`).

## Invariants
- Key casing and comparers: `MarketBook.ItemKey` lowercases `"server|item"` and `MarketBook.Key` lowercases `"server|item|player|(b|s)"`; `Rows` uses `StringComparer.Ordinal` while `Cards` and `Stacks` enforce `StringComparer.OrdinalIgnoreCase` (restored on `Load`).
- Listing admission and UTC normalization: `MarketFeed.TryParse` requires a root JSON object with a `"listings"` array, skips listing entries with empty trimmed `item` or `player`, skips non-positive `stacks` entries and zero-valued item stats, and normalizes timestamps to `DateTimeKind.Utc`; `MarketBook.From` admits only matched (`Matched == true`) `Sell` or `Buy` listings with non-null `Price` (`l.Price is { } lot`) and positive `Unit` (`l.Unit is > 0`).
- Monotonic merge and retention: `MarketBook.Merge` is a no-op when `feed.GeneratedAt <= book.GeneratedAt`, skips rows older than current `Time`, archives prior rows into `History` when `(Copper, Lot, Stack, Quantity)` changes, preserves non-empty `Requests`/`Capture` when a snapshot omits them, and runs `Prune(feed.GeneratedAt)` (`> 45d` unseen `Rows` move to `History`; `> 120d` unseen `History` entries expire).
- Standing vs historical pricing: `MarketItem` counts only `Now` rows seen within `3 days` (`ActiveFor`) as active `Asks` (ascending `Copper`) or `Bids` (descending `Copper`). `MarketMath.Standing` computes `Until = min(Seen + 6h, nextSamePlayerAndIntent.Time)`; `MarketMath.Trend` (via `At`) evaluates point-in-time standing prices over half-open `[Time, Until)`, whereas `MarketMath.Days` matches day intervals using closed boundaries (`s.Price.Time <= end && s.Until >= start`).
- Schema guard, rate-limit precedence, and concurrency: `MarketBook.Load` returns `null` if `FileVersion > MarketBook.Version` (`1`); `MarketRefresh.Decide` enforces `NotBeforeUtc` first (clamped by `BackOff` to `[1m, 1d]`), then `10m` manual cooldown or `6h20m` freshness / `1h` auto-retry cooldown. Mutable types (`MarketBook`, `MarketMeta`, `MarketSnapshot` lazy name map) are not thread-safe. Depends on `AppFolder` and `MnMCompanion.Loot.LootSummary.Coin`.

## Side Effects
- Synchronous disk reads and atomic `.tmp`-move writes of `market.json` (`MarketBook`) and `market.meta.json` (`MarketMeta`) under `AppFolder.Folder`: `MarketBook.Load` catches `IOException`, `UnauthorizedAccessException`, `JsonException`, and `NotSupportedException`; `MarketMeta.Load` catches `IOException`, `UnauthorizedAccessException`, and `JsonException`; both `Save` methods catch `IOException` and `UnauthorizedAccessException`.
- In-memory mutations on `MarketBook` (`Merge`, `Prune`), `MarketMeta` (`BackOff`), and `MarketSnapshot.Named` (lazy lookup cache); fallback `DateTime.UtcNow` reads in `MarketFeed.TryParse` and `MarketRefresh.Age`.
- Zero network requests, background timers, or synchronization locks (HTTP transport is external).
