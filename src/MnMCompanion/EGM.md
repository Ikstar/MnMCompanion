# MnMCompanion

## Overview
`MnMCompanion` ([MnMCompanion.csproj](./MnMCompanion.csproj), [app.manifest](./app.manifest), [app.ico](./app.ico)) is the Windows Presentation Foundation (`net9.0-windows`, `WinExe`, `UseWPF=true`, `PerMonitorV2` DPI) desktop overlay and companion application for *Monsters & Memories*. It presents live loot meters, session/day statistics, zone maps, tradeskill recipes, player auction listings, multi-page historical ledger exploration, and per-character countdown timers without touching the game process, supporting independent per-window UI scaling (`100%`–`200%`), detachable persistent tab overlays (`TabWindow`), and compact ("mini") 3-row summary overlays (`Loot`, `Vendor`, `Items`, `Harvest`). File tailing, scaling/docking policy, and domain models are provided by [`MnMCompanion.Core`](../MnMCompanion.Core/EGM.md), local SQLite persistence and historical queries by [`MnMCompanion.Data`](../MnMCompanion.Data/EGM.md), and HTTPS release/community/market/recipe clients by [`MnMCompanion.Update`](../MnMCompanion.Update/EGM.md).

## Invariants
- **Read-Only Non-Intrusive Game Boundary**: The application never inspects or writes game process memory, installs no keyboard or mouse hooks, and never synthesizes input into the game; global timer shortcuts use Win32 `RegisterHotKey` with `MOD_NOREPEAT` and reject bare alphanumeric keys, and `TabWindow` never uses `WS_EX_TRANSPARENT` click-through or input hooks.
- **Sole NuGet Package & `MapsOnline` Runtime Gate**: `Microsoft.Web.WebView2` is the project's only NuGet `PackageReference` ([MnMCompanion.csproj](./MnMCompanion.csproj)). `PanelWindow` constructs `MapPanel` unconditionally (`App.WebViewState()` also queries `CoreWebView2Environment.GetAvailableBrowserVersionString()` during `--diagnose`), while `Settings.MapsOnline` (`false` by default) strictly gates lazy `WebView2` instantiation (`EnsureWeb()`), `CoreWebView2` browser-process creation (`EnsureCoreWebView2Async`), host-scale zoom sync (`SetHostScale`), and URL navigation; `NavigationStarting` / `NewWindowRequested` restrict in-app navigation to HTTPS `AtlasHost` (`mnmatlas.com`), and `"Try again"` / `CoreWebView2.ProcessFailed` dispose and recreate `_web` cleanly without permanently latching transient errors.
- **Per-Window Scaling, Singleton Tab Handoff & Coalesced Persistence**:
  - Window scales snap to `UiScale.Presets` (`100%`–`200%`), clamping bounds to the nearest monitor's DIP `WorkArea` (skipped only when `WindowScale.GetOffScreenSnapshot` is `true`) and propagating scale to `ContextMenu`s, `ToolTip`s, and child dialogs (`Dialogs.Dress`, `ShareWindow`, `TimerSetupWindow`).
  - All 8 `IMiniPage` instances are singletons shared between `PanelWindow` and `TabWindow` (always clearing `_host.Content = null` before reparenting or `HWND` close to prevent dual-parenting or duplicate `WebView2`/network state), retaining `>= 1` docked tab in `PanelWindow` (`TabDockPolicy.CanDetach`) and invoking `_history.RefreshAsync()` at most once per 2-second poll cycle.
  - `TabWindow` uses `AllowsTransparency = false` and `Owner = null` so `WebView2` renders without layered-window airspace conflicts and pinned tabs stay above the game when `PanelWindow` minimizes. User-initiated `TabWindow` close (`!_shuttingDown`) re-docks the tab (`Open = false`), whereas `PanelWindow.PrepareForExit()` (invoked on `PanelWindow.Closing`, `UpdateController.Restarting`, and `App.OnExit`) sets `_shuttingDown = true` so open `DetachedTabs` reopen on next launch.
  - All windows coalesce geometry/scale writes through a single 1-second `Settings.SaveSoon()` timer, `Settings.FlushSave()` writes only when `_saveSoon` has a pending write, and `Settings.Normalize()` sanitizes non-finite/non-positive bounds and repairs invalid `DetachedTabs` states on load.
- **Embedded Changelog & Exact `ProductVersion`**: `CHANGELOG.md` is compiled into the assembly as an `EmbeddedResource` (`LogicalName="CHANGELOG.md"`) so `WhatsNewWindow` renders release notes offline; `IncludeSourceRevisionInInformationalVersion` is `false` so the binary's `ProductVersion` equals `<Version>` without a `+<commit>` suffix to satisfy code-signing policy checks.
- **Versioned Consent & Reciprocity Gating**: `Settings.Sharing` delegates to `CommunityPolicy.Consented`, holding only when `ShareWithCommunity` is `true` and `Math.Max(1, ShareConsentSchema) >= ContributionBuilder.Schema` (treating unrecorded `0` as schema `1`); schema additions pause automatic uploads (`ConsentNeedsRenewal`) and `CommunityReader` lookups until re-approved. `SuggestionWindow` sends only user-typed text, app version, and `ContributorId` on explicit user action regardless of `Settings.Sharing`, while `RecipesOnline` and `MarketOnline` send no ledger data and honor offline toggles and `--recipes` / `--market` local file overrides.
- **Custom-Ledger Isolation & Headless CLI Modes**: Passing `--ledger` routes state and SQLite storage to `LedgerDb.OtherFolder` / `OtherDb` (`--db` overrides the database path in `--archive` and `--contribute`) and—like all headless CLI flags (`--about`, `--diagnose`, `--contribute`, `--archive`, `--snapshot`)—marks `Settings.ReadOnly = true` so test/diagnostic runs never overwrite `settings.json` or restore detached `TabWindow` overlays; headless modes terminate before opening interactive loops, and `--diagnose` (`display:` / `windows:`) and `--about` (`Scales:`) emit zero character names while masking OS usernames in paths.
- **UI-Thread Update & Overlay Lifecycle Safety**: `UpdateController` mutates state exclusively on the UI thread, verifies release SHA-256 checksums, fires `Restarting` before `Application.Current.Shutdown()`, and—only during automatic installs (`byItself: true`, not manual `InstallAsync()` or `RestartNow()`)—waits while `TimersWindow.AnyRunning` is `true` and records `AutoInstalledVersion` to prevent automatic restart loops. `TimersWindow`'s title-bar `✕` button calls `Hide()` so running timers, hotkeys, and sound alerts continue while hidden, whereas OS-level `Window.Closed` disposes `_hotkeys` and stops `_keyWatch`; `TimerSetupWindow` suspends `HotkeyHost` registrations during key capture.

## Side Effects
- **Settings, Caches, Reports & Scratch Disk I/O**: Atomically writes `%LOCALAPPDATA%\MnMCompanion\settings.json` (`Settings.Folder`, overridable via `MNMCOMPANION_DATA`) via `.tmp` + `File.Move` when `!Settings.ReadOnly` (and backs up unreadable files to `settings.json.corrupt` during `Settings.Load()`); persists `recipes.json` / `recipes.meta.json` and `market.json` / `market.meta.json` when `!Settings.ReadOnly`, per-character `timers.json` and `sessions.json` / `sessions\*.txt`, and WebView2 user data under `<StateRoot>\webview`; stages updates under `%LOCALAPPDATA%\MnMCompanion\update`; writes CLI reports (`about.txt`, masked `diagnose-report.txt`, `archive-report.txt`, `contribute-report.txt`, or `--report <path>`), exported `<contributor>[.npcs|.trades].json` files, `--snapshot` PNGs, and `<png>.txt` (`window WxH  content WxH  scale S%  dpi D`) geometry/scale/DPI sidecars across `--snapshot` window targets; creates and cleans up `%TEMP%` scratch files/folders (`mnmcompanion-test-<guid>.png`, `mnmcompanion-snapshot-<guid>.db`, `mnmcompanion-timers-<guid>`); reads the embedded `CHANGELOG.md` stream; and inspects Wine/Proton environment variables and `Z:\` Linux prefixes.
- **Win32 Monitor Queries, Taskbar Icons, Hotkeys, Click-Through Styles, DWM & Shell Dialogs**: P/Invokes `user32.dll` `MonitorFromWindow`, `MonitorFromRect`, and `GetMonitorInfoW` in [WindowScale.cs](./WindowScale.cs) for per-monitor DIP work-area clamping; P/Invokes `user32.dll` `CreateIconFromResourceEx`, `LoadImageW`, `GetSystemMetrics`, `SendMessageW` (`WM_SETICON`), `GetWindowLongW` / `SetWindowLongW` (`WS_SYSMENU` / `WS_MINIMIZEBOX`), and `SetWindowPos`, plus `kernel32.dll` `GetModuleHandleW`, in [Ui.cs](./Ui.cs) so borderless `WindowChrome` windows display their icon on the Windows Taskbar; P/Invokes `user32.dll` `RegisterHotKey` / `UnregisterHotKey` on a zero-size `HWND_MESSAGE` `HwndSource` in [HotkeyHost.cs](./HotkeyHost.cs); toggles `WS_EX_TRANSPARENT` (`0x20`) via `user32.dll` `GetWindowLongW` / `SetWindowLongW`, polls `GetAsyncKeyState` on a `60ms` timer, and hooks `WM_ENTERSIZEMOVE` / `WM_EXITSIZEMOVE` in [TimersWindow.cs](./TimersWindow.cs); sets DWM dark title-bar attributes via `dwmapi.dll` `DwmSetWindowAttribute` in [Dialogs.cs](./Dialogs.cs), [HistoryWindow.xaml.cs](./HistoryWindow.xaml.cs), and [ShareWindow.cs](./ShareWindow.cs); applies custom `WindowChrome` with `PerMonitorV2` DPI awareness ([app.manifest](./app.manifest)); and opens Win32 `OpenFolderDialog`, `OpenFileDialog`, `SaveFileDialog`, and `MessageBox` prompts.
- **Audio Playback**: Plays Windows `SystemSounds` and local/system `.wav` files via `System.Media.SoundPlayer` in [TimerSoundPlayer.cs](./TimerSoundPlayer.cs), throttling grouped corpse-timer alerts to a 1.5-second minimum interval.
- **WebView2 Hosting, Clipboard & Process Spawning**: Queries Edge WebView2 runtime availability via `GetAvailableBrowserVersionString()` during `--diagnose`, initializes `CoreWebView2` and navigates to `mnmatlas.com` in [MapPanel.cs](./MapPanel.cs) when `Settings.MapsOnline` is enabled, copies user-selected summaries/recipes to the Windows clipboard, opens ledger folders in Explorer (`LootPanel.OpenFolder`, `LootHistoryPage.OnOpenFolder`) and external HTTP/HTTPS URLs in the system browser (`UseShellExecute = true`), and spawns replacement executables with `--updated` during self-update restarts.
- **Delegated SQLite & HTTPS I/O**: Delegates game ledger/journal polling, per-character `TimerBook` persistence, `MarketBook` snapshots, and recipe cache files to [`MnMCompanion.Core`](../MnMCompanion.Core/EGM.md); delegates SQLite database creation, ingestion passes, and historical queries (`LedgerDb`, `HistoryStore`, `CommunityExport`) to [`MnMCompanion.Data`](../MnMCompanion.Data/EGM.md); and delegates all HTTPS requests (GitHub release checks/downloads via `UpdateService`, community uploads/queries/suggestions via `CommunityClient`, `mnm-db.com` auction fetches via `MarketFeedClient`, and wiki recipe fetches via `RecipeWikiClient`) to [`MnMCompanion.Update`](../MnMCompanion.Update/EGM.md).
