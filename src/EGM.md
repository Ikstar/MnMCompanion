# src

## Overview
`src` houses the four production C# / `.NET 10` projects that make up Companion for Monsters & Memories (`MnMCompanion`). The subsystem enforces a strict radial dependency architecture around a pure-BCL core domain library (`MnMCompanion.Core`), isolating SQLite storage in `MnMCompanion.Data`, isolating `HttpClient` / `System.Net` outbound HTTPS and self-update operations in `MnMCompanion.Update`, and composing them inside the Windows WPF desktop overlay executable (`MnMCompanion`).

## Subdirectories & Boundaries
- **MnMCompanion**: [./MnMCompanion/EGM.md](./MnMCompanion/EGM.md) - Windows WPF (`net10.0-windows`, `WinExe`) desktop overlay and companion application hosting live loot/map/recipe/market panels, multi-page ledger history explorer, per-character timer overlays, Win32 global hotkeys, `settings.json` persistence, and community/self-update UI controllers.
- **MnMCompanion.Core**: [./MnMCompanion.Core/EGM.md](./MnMCompanion.Core/EGM.md) - Pure `.NET 10` BCL domain library (`RootNamespace = MnMCompanion`) resolving and migrating local application storage via `AppFolder` and rolling up eight domain packages (`Community`, `History`, `Journal`, `Ledger`, `Loot`, `Market`, `Recipes`, `Timers`) with zero NuGet, database, network, or UI dependencies.
- **MnMCompanion.Data**: [./MnMCompanion.Data/EGM.md](./MnMCompanion.Data/EGM.md) - Local SQLite persistence and query package (`net10.0`, referencing only `MnMCompanion.Core` and `Microsoft.Data.Sqlite`) handling append-only game ledger and NPC journal archiving, derived event-table projection, historical queries, and anonymized community export assembly.
- **MnMCompanion.Update**: [./MnMCompanion.Update/EGM.md](./MnMCompanion.Update/EGM.md) - Zero-package, BCL-only outbound HTTPS and release-management library (`net10.0`) owning GitHub Releases version checks, SHA-256-verified self-update downloads and atomic binary replacement, `CHANGELOG.md` release-note parsing, opt-in community intake/query HTTP calls plus user-initiated `POST /v1/suggestion` submissions, conditional ETag fetches for market/wiki feeds, and zone-to-atlas URL mapping.

## Invariants
- **Strict Dependency Graph & Assembly Reference Allowlists** (enforced by [LedgerOnlyTests.cs](../tests/MnMCompanion.Tests/LedgerOnlyTests.cs)):
  - `MnMCompanion.Core` references neither `MnMCompanion.Data` nor `MnMCompanion.Update`, carries zero `PackageReference` entries, and compiles strictly against `.NET` BCL assemblies.
  - `MnMCompanion.Data` and `MnMCompanion.Update` never reference each other; `Data` is the sole project allowed to reference `Microsoft.Data.Sqlite` (referencing only `System*`, `Microsoft.Data.Sqlite`, and `MnMCompanion.Core`), and `Update` carries zero `PackageReference` or `ProjectReference` entries (referencing only `System*` BCL assemblies).
  - `MnMCompanion` (the WPF executable) is the sole project referencing all three libraries and carries `Microsoft.Web.WebView2` as its only `PackageReference`. While `MapPanel` constructs `new WebView2()` unconditionally in its visual tree (and `--diagnose` queries `CoreWebView2Environment.GetAvailableBrowserVersionString()`), initializing the `CoreWebView2` browser runtime (`EnsureCoreWebView2Async`) and navigating to `www.mnmatlas.com` are gated behind `Settings.MapsOnline == true`.
- **Read-Only Game & Forbidden Token Boundary** ([LedgerOnlyTests.cs](../tests/MnMCompanion.Tests/LedgerOnlyTests.cs)): No `.cs`, `.xaml`, or `.csproj` file under `src` may reference game-process/memory/input/IPC/legacy-DB tokens (`Memento`, `world.db`, `observations.db`, `System.Data`, `WebRequest`, `WebClient`, `Socket`, `OpenProcess`, `ReadProcessMemory`, `GetProcessesByName`, `Process.GetProcess`, `MemoryMappedFile`, `NamedPipe`, `SendInput`, `SetCursorPos`, `keybd_event`, `mouse_event`, `Interception`), and game ledger/journal files are opened strictly read-only.
- **Network Confinement**: Only `MnMCompanion.Update` may reference `HttpClient` / `System.Net` or contain `https://` literals in `.cs` source files, restricted to allowlisted hosts (`github.com`, `api.github.com`, `www.mnmatlas.com`, `mnm-intake.mnm-companion.workers.dev`, `monstersandmemories.wiki`, `mnm-db.com`).

## Side Effects
- Reads game Character/Social JSON ledgers and NPC dialogue journals from Windows `LocalLow` or Linux Wine/Proton prefixes (Steam `libraryfolders.vdf`, Flatpak Steam, UMU `Games/umu/*`, Lutris `Games/*` and `Games/*/prefix`, `~/.wine`, and `WINEPREFIX` / `STEAM_COMPAT_DATA_PATH`) without modifying game files.
- Resolves `%LOCALAPPDATA%\MnMCompanion` (with one-time legacy `%LOCALAPPDATA%\LootWindow` migration when `MNMCOMPANION_DATA` is unset) or `other-ledgers\<12-hex-sha256>\` for `--ledger` runs, persisting root files (`settings.json`, `ledger.db` + `-wal`/`-shm`, `market.json`, `market.meta.json`, `recipes.json`, `recipes.meta.json`, `update\*`, `webview\*`, and CLI reports `about.txt`, `diagnose-report.txt`, `archive-report.txt`, `contribute-report.txt`), per-character files (`<Server>-<Character>\sessions.json`, `<Server>-<Character>\timers.json`, and non-`.tmp` `<Server>-<Character>\sessions\<yyyy-MM-dd HHmm>-<HHmm>.txt` breakdowns), user-exported `<contributor>[.npcs|.trades].json` files, and `--snapshot` `.png`/`.png.txt` renders plus `%TEMP%` scratch files.
- Performs Win32 `RegisterHotKey` bindings, `WS_EX_TRANSPARENT` click-through and `dwmapi.dll` dark title-bar styling, audio alert playback, clipboard/Explorer/browser shell calls, `Settings.MapsOnline`-gated `CoreWebView2` atlas navigation, and allowlisted HTTPS calls via `MnMCompanion.Update`.
