# MnMCompanion Blueprint

## System Overview
Companion for Monsters & Memories ([MnMCompanion.sln](./MnMCompanion.sln)) is a Windows WPF desktop companion application (`.NET 10`) that passively tails the game's on-disk JSON ledger files and character NPC dialogue journals to track group loot splits, vendor valuations, drop rates, harvests, player trades, countdown/corpse timers, tradeskill recipes, and auction house price books without ever attaching to or interacting with the game client process. Its desktop UI supports independent per-window UI scaling (`100%`–`200%` presets across `PanelWindow`, `HistoryWindow`, `TimersWindow`, and detached tab windows), persistent detachable tab overlays (`TabWindow`) that share the active character and session timeline while keeping at least one tab docked in `PanelWindow`, and compact ("mini") 3-row live summary overlays on popped-out `Loot`, `Vendor`, `Items`, and `Harvest` windows.

The repository separates production application and library code ([./src/EGM.md](./src/EGM.md)) from release, synthetic fixture, and screenshot automation ([./scripts/EGM.md](./scripts/EGM.md)), backed by an offline xUnit test and architectural-boundary verification project ([tests/MnMCompanion.Tests/MnMCompanion.Tests.csproj](./tests/MnMCompanion.Tests/MnMCompanion.Tests.csproj)), GitHub Actions CI/Release pipelines ([.github/workflows/ci.yml](./.github/workflows/ci.yml), [.github/workflows/release.yml](./.github/workflows/release.yml)), SignPath signing configuration ([.signpath/artifact-configurations/default.xml](./.signpath/artifact-configurations/default.xml)), and player-facing documentation ([README.md](./README.md), [CHANGELOG.md](./CHANGELOG.md), [docs/FAQ.md](./docs/FAQ.md), and [docs/ledger-notes.md](./docs/ledger-notes.md)).

## Subdirectories & System Boundaries
- **src**: [./src/EGM.md](./src/EGM.md) - Production `.NET 10` projects (`MnMCompanion` WPF desktop overlay, `MnMCompanion.Core` pure-BCL domain engine, `MnMCompanion.Data` SQLite archive/query layer, and `MnMCompanion.Update` BCL-only HTTPS and self-update client library).
- **scripts**: [./scripts/EGM.md](./scripts/EGM.md) - PowerShell and Python release builders, `CHANGELOG.md` release-note extractors, deterministic synthetic ledger/market fixture generators, and headless `--snapshot` screenshot automation.
- **tests/MnMCompanion.Tests** (test-only suite, [MnMCompanion.Tests.csproj](./tests/MnMCompanion.Tests/MnMCompanion.Tests.csproj)): Offline `net10.0` xUnit suite verifying domain logic, SQLite archiving, HTTP client contracts, source/assembly boundary enforcement ([LedgerOnlyTests.cs](./tests/MnMCompanion.Tests/LedgerOnlyTests.cs)), and changelog integrity ([ChangelogTests.cs](./tests/MnMCompanion.Tests/ChangelogTests.cs)).
- **docs** (non-code documentation): Player [FAQ.md](./docs/FAQ.md), ledger format reference ([ledger-notes.md](./docs/ledger-notes.md)), design specifications under `docs/designs/`, and rendered UI screenshots under `docs/images/`.

## Global Invariants
- **Strict Passive File-Only Game Boundary** (enforced by [LedgerOnlyTests.cs](./tests/MnMCompanion.Tests/LedgerOnlyTests.cs)): The system's sole game inputs are on-disk JSON ledger files (`Character` and `Social`) and per-character NPC journal text files opened with `FileShare.ReadWrite | FileShare.Delete`. Source-level bans forbid third-party DBs (`Memento`, `world.db`, `observations.db`, `System.Data`), raw sockets/IPC/legacy HTTP (`WebRequest`, `WebClient`, `Socket`, `MemoryMappedFile`, `NamedPipe`), game process/memory inspection (`OpenProcess`, `ReadProcessMemory`, `GetProcessesByName`, `Process.GetProcess`), and input hooks/synthesis (`SendInput`, `SetCursorPos`, `keybd_event`, `mouse_event`, `Interception`).
- **Capability & Assembly Reference Confinement** ([LedgerOnlyTests.cs](./tests/MnMCompanion.Tests/LedgerOnlyTests.cs)):
  - `MnMCompanion.Core` is strictly pure `.NET 10` BCL (`0` NuGet packages, `0` project references, `System*`-only assembly references), including pure window-scaling math (`UiScale`, `100%`–`200%` presets and work-area clamping) and detachable-tab docking/compact policy (`TabDockPolicy`).
  - `MnMCompanion.Data` is the sole project permitted to reference `Microsoft.Data.Sqlite` (`System*`, `Microsoft.Data.Sqlite*`, and `MnMCompanion.Core` assembly references only) and never references `MnMCompanion.Update`.
  - `MnMCompanion.Update` is a zero-package, `System*`-only BCL project and the sole project permitted to reference `HttpClient` / `System.Net` or contain `https://` literals in `.cs` files, restricted to allowlisted hosts (`api.github.com`, `github.com`, `www.mnmatlas.com`, `mnm-intake.mnm-companion.workers.dev`, `monstersandmemories.wiki`, `mnm-db.com`).
  - `MnMCompanion` (WPF `WinExe`) carries `Microsoft.Web.WebView2` as its sole NuGet package. While `--diagnose` queries `CoreWebView2Environment.GetAvailableBrowserVersionString()`, `MapPanel` lazily instantiates its recoverable `WebView2` control, initializes `CoreWebView2` (`EnsureCoreWebView2Async`), syncs host window zoom, and navigates to `www.mnmatlas.com` only when `Settings.MapsOnline` is opted into (`false` by default). Detached `TabWindow` overlays use opaque borderless `WindowChrome` (`AllowsTransparency = false`, `Owner = null`, zero `WS_EX_TRANSPARENT` or input hooks), retain `>= 1` docked tab in `PanelWindow`, and expose compact mode strictly on `Loot`, `Vendor`, `Items`, and `Harvest`.
- **Privacy, Consent & Suggestion Gates**: Community dataset consumption and contribution uploads (`Settings.Sharing`) require explicit opt-in (`ShareWithCommunity == true`) with `Math.Max(1, ShareConsentSchema) >= ContributionBuilder.Schema` (`4`), export strictly `Character` rows (never `Social` rows), scrub player names from NPC dialogue, and use an unlinked local random contributor GUID (`LedgerDb.ContributorId()`). Separate from `Settings.Sharing`, user-initiated `POST /v1/suggestion` (`SuggestionWindow` / `--suggest`) sends user-typed suggestion text (`<= 2000` chars), app version, and `ContributorId()` only when the user clicks `Send`. `--diagnose` (`display:` and `windows:` lines redacted via `GameFolderFinder.Mask`) and `--about` (`Scales:` summary line) emit only numeric DPI/work-area/scale values and canonical tab names—never character or player names. Alternate `--ledger` folders isolate SQLite storage via `LedgerDb.OtherFolder` (unless `--db` overrides it in `--archive`/`--contribute`) and, together with all headless CLI modes (`--about`, `--diagnose`, `--archive`, `--contribute`, `--snapshot`), force `Settings.ReadOnly = true`.
- **Changelog, Release & Code-Signing Integrity** ([ChangelogTests.cs](./tests/MnMCompanion.Tests/ChangelogTests.cs), [.github/workflows/release.yml](./.github/workflows/release.yml), [.signpath/artifact-configurations/default.xml](./.signpath/artifact-configurations/default.xml)):
  - [CHANGELOG.md](./CHANGELOG.md) is embedded into `MnMCompanion.exe` for offline What's New rendering, must contain a non-empty `## <Version> (yyyy-mm-dd)` section matching `<Version>` in [src/MnMCompanion/MnMCompanion.csproj](./src/MnMCompanion/MnMCompanion.csproj), must list unique versions and dates strictly newest-first, and every entry `>= 0.4.1` must include a `**Sharing` or `**Network` disclosure line.
  - `IncludeSourceRevisionInInformationalVersion=false` keeps `ProductVersion` exact (`X.Y.Z` without `+<commit>`), release tags `v<Version>` must match `<Version>`, SignPath signing (`SIGNING_ENABLED == 'true'`) verifies Authenticode signatures before publishing, and `UpdateService` enforces `MZ` header and SHA-256 digest checks before atomic `.old` swap/rollback replacement.

## Global Side Effects
- **Local App Data Storage**: Resolves `%LOCALAPPDATA%\MnMCompanion` (or `MNMCOMPANION_DATA` override; one-time legacy migration from `%LOCALAPPDATA%\LootWindow` when un-overridden), storing root files (`settings.json` plus best-effort `settings.json.corrupt` backup on unreadable JSON, `ledger.db` + `-wal`/`-shm`, `market.json`, `market.meta.json`, `recipes.json`, `recipes.meta.json`, `update\*`, `webview\*`, `other-ledgers\<12-hex-sha256>\*`, and default CLI reports `about.txt` with `Scales:` summary, `diagnose-report.txt` with masked `display:` / `windows:` telemetry, `archive-report.txt`, `contribute-report.txt`), per-character files under `<Server>-<Character>\` (`sessions.json`, `timers.json`, and `sessions\<yyyy-MM-dd HHmm>-<HHmm>.txt` breakdowns), user-saved `<contributor>[.npcs|.trades].json` exports, and `--snapshot` `.png` renders (supporting `--scale <percent>`, `--popout <page>`, and `--compact`) plus `.png.txt` geometry/scale/DPI sidecars (`window WxH  content WxH  scale S%  dpi D`) and `%TEMP%` scratch files.
- **Read-Only Game Directory Discovery & Polling**: Probes Windows `LocalLow` and Linux Wine/Proton prefixes (Steam `libraryfolders.vdf`, Flatpak Steam, UMU `Games/umu/*`, Lutris `Games/*` and `Games/*/prefix`, `~/.wine`, `WINEPREFIX`, and `STEAM_COMPAT_DATA_PATH`) and polls character ledger and journal files without modifying game directories.
- **Desktop OS Integration**: Queries per-monitor work areas (`MonitorFromWindow` / `MonitorFromRect` / `GetMonitorInfoW` in `user32.dll`) for `PerMonitorV2` DPI-aware `100%`–`200%` per-window UI scaling across main, history, timer, dialog, and detachable `TabWindow` overlays (including compact mode on `Loot`, `Vendor`, `Items`, and `Harvest`); registers global Win32 `MOD_NOREPEAT` hotkeys (`user32.dll`); toggles `TimersWindow` `WS_EX_TRANSPARENT` click-through window styles and `dwmapi.dll` dark title-bar attributes; plays local `.wav`/system alert sounds; opens clipboard/Explorer/browser shell targets; and hosts `Settings.MapsOnline`-gated `CoreWebView2` zone maps.
- **Allowlisted Outbound HTTPS**: Checks/downloads GitHub Releases, fetches conditional-ETag public tradeskill wiki and auction feeds (unless disabled), submits/queries anonymized community data when `Settings.Sharing` is active, and submits user-initiated feedback via `POST /v1/suggestion`.
- **Build, CI & Artifact Tooling (`scripts/`, `.github/workflows/`)**: Runs `dotnet build` / `dotnet test` in Release on `windows-latest`, publishes `win-x64` single-file `dist/MnMCompanion.exe` + `.sha256` (optionally signed via SignPath), generates deterministic demo fixtures (`random.Random(2026)`), and renders cropped UI PNGs into `docs/images/`.
